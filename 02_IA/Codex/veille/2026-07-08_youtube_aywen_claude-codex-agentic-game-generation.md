## 3. Resume synthetique

La source presente une experimentation de creation de jeu video de type monde ouvert avec des agents IA. Le createur compare notamment une version produite avec Codex / ChatGPT et une version produite avec Claude, en ajoutant des outils specialises pour generer modeles 3D, textures, sons, voix et cinematics.

L'interet principal pour AOS est l'observation d'un workflow agentique multimodal : un modele de code agit comme orchestrateur, decompose des demandes complexes, appelle des modeles specialises, integre les assets dans un jeu, puis itere sur les bugs et les fonctionnalites. Le contenu reste cependant une demonstration YouTube non reproductible, sponsorisee, et centree sur un resultat spectaculaire plutot que sur une evaluation methodique.

## 4. Faits validables

- La source montre un usage de Codex / ChatGPT pour generer une base de jeu et iterer sur des fonctionnalites.
- La source montre un usage de Claude pour produire une version concurrente du meme type de projet.
- Le workflow combine code, assets 3D, textures, sons, voix, cinematiques et logique de jeu.
- Des limites pratiques apparaissent : bugs de physique, performance, integration imparfaite des modeles 3D, murs invisibles, comportements instables.
- Le createur distingue le resultat impressionnant d'un produit commercialisable et signale que le code source est probablement de faible qualite.
- Le cout augmente avec les appels repetes a des modeles specialises.

## 5. Hypotheses

- Codex peut servir d'orchestrateur pour des prototypes interactifs complexes si les objectifs sont decoupes en etapes verificables.
- Claude semble mieux accepter les demandes couteuses ou ambitieuses dans cette demonstration, mais cette observation n'est pas suffisante pour etablir une superiorite generale.
- Les workflows de creation de jeux par agents IA peuvent devenir utiles pour prototypage, mais restent insuffisants pour production sans supervision humaine forte.
- L'orchestration d'assets externes exige des garde-fous de cout, de qualite, de performance et de droits d'usage.
