# Collecte

Zone d'entree des informations.

Les sources passent par cette zone avant toute qualification. Une information collectee n'est pas consideree comme validee tant qu'elle n'a pas ete analysee et integree dans une fiche de veille.

## Sous-zones

- `sources_brutes/` : contenu entrant non traite.
- `a_qualifier/` : contenu a analyser.
- `qualifiees/` : contenu analyse et exploitable pour une fiche de veille.
- `rejetees/` : contenu ecarte avec raison de rejet si necessaire.
