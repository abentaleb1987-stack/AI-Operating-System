9 skills et plugins gratuits qui rendent Claude Code, Codex et autres agents de programmation IA bien plus performants. Et oui, ils sont tous gratuits !

Les skills et plugins sont des fichiers d'instructions réutilisables qui permettent à votre agent IA d'adopter un comportement reproductible, évitant ainsi de repartir de zéro à chaque fois. Dans cette vidéo, je vous présente 9 de mes outils préférés, je les installe en direct et je compare plusieurs d'entre eux pour que vous puissiez constater précisément les différences.

J'aborde GStack (qui transforme Claude Code en une véritable équipe d'ingénierie virtuelle), Stop Slop (qui supprime les annotations de l'IA dans votre code), Graphify (qui transforme n'importe quel code source ou base de connaissances en un graphe interrogeable utilisable comme mémoire par votre agent), Understand Anything (des cartes d'intégration visuelles pour tout code source), Last 30 Days (une analyse des sentiments en temps réel sur Reddit, X, YouTube et autres plateformes), les skills Front End Design et Taste d'Anthropic (des tests de conception comparatifs), et ReMotion vs HyperFrames (des animations générées par l'IA à partir d'une simple commande).

Chaque compétence est compatible avec Claude Code, Codex, Cursor, OpenClaw, Hermes, VS Code et GitHub Copilot. Vous trouverez les liens vers chacun d'eux ci-dessous.
