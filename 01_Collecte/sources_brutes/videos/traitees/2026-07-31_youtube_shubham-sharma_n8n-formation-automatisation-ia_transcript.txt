Ce que vous allez comprendre dans cette vidéo, c'est comment construire des automatisations robustes avec n8n de A à Z — des fondamentaux qui resteront valables malgré les mises à jour, même si vous n'êtes pas développeur.

On commence par l'interface et le canevas, et votre toute première automatisation : un déclencheur + une action, la machine à café. Puis cas d'usage n°1 : recevoir chaque matin la photo du jour de la NASA par Gmail — l'occasion de comprendre les nœuds, les credentials, les clés API et les variables. Ensuite les 3 types d'installation (cloud, en local sur votre ordinateur, ou self-hosted sur un VPS), les grandes familles de nœuds (déclencheurs, actions, transformation de données, flows if/switch), puis cas d'usage n°2 : filtrer des annonces immobilières depuis un flux RSS avec du code JavaScript écrit par Claude, un switch et les data tables de n8n — avant d'y ajouter une IA qui rédige le message pour l'agence. Après un point essentiel sur le JSON, les expressions et le nœud HTTP (pour connecter n'importe quelle API, même sans nœud dédié — exemple avec Granola), on termine avec le cas d'usage n°3 : un agent IA qui lit vos emails et prépare des brouillons de réponse dans Gmail, et en bonus le MCP de n8n connecté à Claude Code, qui crée un workflow complet tout seul.
