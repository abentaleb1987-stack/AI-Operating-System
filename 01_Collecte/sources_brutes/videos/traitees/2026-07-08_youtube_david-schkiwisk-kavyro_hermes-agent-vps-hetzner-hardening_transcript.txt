Installer Hermes Agent sur un VPS Hetzner, ce n’est pas compliqué.

Dans ce tutoriel, je te montre une installation propre de A à Z sur Ubuntu 24.04 :

firewall Hetzner
connexion root initiale
création du user hermes
copie de la clé SSH
configuration UFW
durcissement SSH
installation de Fail2ban
update serveur
installation et setup de Hermes Agent

Objectif : repartir avec un serveur propre, sécurisé, et un Hermes fonctionnel.
