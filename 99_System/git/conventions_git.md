# Conventions Git

## Nommage

- Utiliser des noms de fichiers courts et explicites.
- Eviter les renommages inutiles.
- Garder une structure stable pour faciliter l'automatisation.

## Commits recommandes

- `init:` initialisation de structure.
- `docs:` documentation ou regles projet.
- `veille:` ajout ou mise a jour d'une fiche de veille.
- `ia:` mise a jour d'une fiche permanente IA.
- `template:` ajout ou modification de template.
- `archive:` archivage d'une source, fiche ou decision.

## Regle de modification

Une mise a jour de fiche permanente doit correspondre a une difference validee, pas a une reecriture globale.
