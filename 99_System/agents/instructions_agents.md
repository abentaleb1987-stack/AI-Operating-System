# Instructions agents

## Regle principale

Les agents IA doivent respecter le cycle officiel :

Source -> Collecte -> Qualification -> Fiche de veille -> Validation -> Mise a jour de la fiche permanente -> Archivage

## Contraintes

- Ne jamais modifier une fiche permanente directement depuis une source brute.
- Ne jamais reecrire une fiche permanente en entier.
- Proposer uniquement les differences validees a integrer.
- Conserver les informations marketing, speculatives ou non verifiees dans la veille.
- Archiver les elements traites lorsqu'ils sortent du cycle actif.
- Respecter les ADR, les Standards, les Frameworks et les Templates.
- Ne pas inventer une nouvelle architecture sans validation.
