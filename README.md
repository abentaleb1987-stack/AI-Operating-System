# AI Operating System - BDD IA

Base de connaissances personnelle sur l'intelligence artificielle.

Objectif : transformer les informations issues de l'experience, de la veille et de la documentation en connaissances durables pour selectionner, comparer, orchestrer et exploiter les meilleures IA selon chaque contexte metier.

## Methode officielle

Source -> Collecte -> Qualification -> Fiche de veille -> Validation -> Mise a jour de la fiche permanente -> Archivage

## Zones principales

- `00_Documentation/` : methode, conventions et documentation projet.
- `01_Collecte/` : sources brutes et informations en qualification.
- `02_IA/` : fiches permanentes, veille, prompts, workflows, decisions et integrations par IA ou domaine prioritaire.
- `03_Frameworks/` : processus operationnels de traitement, organisation et decision.
- `04_Templates/` : modeles Markdown officiels.
- `05_Archives/` : historique des sources, fiches et decisions sorties du cycle actif.
- `06_Scripts/` : emplacement reserve aux automatisations futures.
- `07_Standards/` : regles transversales applicables a tout le projet.
- `99_System/` : instructions agents, schemas et conventions Git.

## Architecture de reference

- Instructions = contrat global du projet.
- Standards = regles transversales.
- Frameworks = processus operationnels.
- Templates = formats d'application.
- IA = connaissances capitalisees.
- Scripts = automatisation.
- System = gouvernance technique.
