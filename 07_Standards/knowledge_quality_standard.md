# Knowledge Quality Standard

## Objectif

Maintenir une base synthetique, fiable et exploitable.

## Regles

- Distinguer fait verifie, retour d'experience, hypothese et contenu marketing.
- Conserver les informations non validees dans les fiches de veille.
- Integrer dans les fiches permanentes uniquement les differences validees.
- Documenter les decisions strategiques avec une justification.
- Preferer une synthese exploitable a une accumulation de notes.
