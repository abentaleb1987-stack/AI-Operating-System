# Documentation Standard

## Objectif

Garantir une documentation durable et facile a maintenir.

## Regles

- Chaque dossier principal doit contenir un `README.md`.
- Les documents doivent indiquer clairement leur role.
- Les templates appliquent les Standards et les Frameworks, mais ne definissent pas la methode.
- Les ADR documentent les decisions d'architecture structurantes.
- Les fichiers doivent rester lisibles sans outil specifique.
