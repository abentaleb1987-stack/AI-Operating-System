# Naming Standard

## Objectif

Garantir des noms stables, explicites et compatibles avec Git et les futures automatisations.

## Regles

- Utiliser des noms courts et descriptifs.
- Eviter les renommages sans raison structurelle.
- Utiliser `README.md` pour documenter les dossiers principaux.
- Utiliser le prefixe `ADR-0000-` pour les decisions d'architecture.
- Nommer les fiches de veille avec une date lorsque le contenu est lie a une source.
