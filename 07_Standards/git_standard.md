# Git Standard

## Objectif

Rendre l'evolution de la base auditable.

## Regles

- Commiter des changements coherents et limites.
- Eviter les modifications massives non justifiees.
- Ne pas reecrire entierement une fiche permanente lorsqu'une difference suffit.
- Archiver les elements utiles a la tracabilite.

## Prefixes recommandes

- `init:` initialisation de structure.
- `docs:` documentation ou regles projet.
- `veille:` fiche de veille.
- `ia:` fiche permanente IA.
- `template:` template Markdown.
- `standard:` standard transversal.
- `framework:` processus operationnel.
- `adr:` decision d'architecture.
- `archive:` archivage.
