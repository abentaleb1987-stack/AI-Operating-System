# Frameworks

Les Frameworks definissent les processus operationnels du projet.

Ils repondent a la question : comment executer un processus ?

## Frameworks principaux

- `knowledge_processing/` : transformer une source d'information en connaissance exploitable.
- `knowledge_organization/` : organiser, maintenir et faire evoluer la base de connaissances.
- `knowledge_decision/` : exploiter la base pour produire des decisions.

Les Frameworks utilisent les Standards. Ils ne definissent pas les regles transversales du projet.
